# Личная страница «Предприниматель и стартапер» — ЛР №4

Учебный проект по веб-технологиям. Лабораторная работа №4. Автор: Амбурцева Алёна

## О проекте

Одностраничный сайт-визитка в оранжево-белых тонах, дополненный JavaScript-скриптом для анализа финансовых показателей (вариант 16). Скрипт приветствует пользователя, анализирует массив дневной выручки и выводит статистические данные.

## Файлы проекта

- `lab_4.html` (или `index.html`) — главная страница
- `lab_4.css` — стили
- `script.js` — скрипт с логикой анализа выручки (новый файл)
- `README.md` — описание (этот файл)
- `images/photo.jpg` — моё фото

## Что реализовано (Требования ЛР №4, Вариант 16)

- **Ввод/вывод:** `prompt` запрашивает имя, `alert` выводит приветствие и итог, `console.log` — технические данные.
- **Массив данных:** 7 значений дневной выручки в рублях.
- **Функции:**
  - `findMax` — поиск максимальной дневной выручки.
  - `filterHighRevenue` — фильтрация дней с выручкой > 10 000 ₽.
  - `calculateSum` — подсчет общей суммы выручки за период.
- **Цикл:** подсчёт количества дней с низкой выручкой (≤ 3 000 ₽) и расчёт их доли в процентах.
- **Вывод в `alert`:** «Общая выручка – X ₽, в Y днях показатели были высокими».
- **Вывод в консоль:** количество дней с низкой выручкой и их процентная доля.
- **Дополнительное условие:** если средняя выручка < 5 000 ₽, в консоль выводится рекомендация «Стоит проанализировать причины низкой выручки».
